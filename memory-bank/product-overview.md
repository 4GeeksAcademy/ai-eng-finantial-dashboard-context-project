# Product Overview

## What this repository delivers
A financial metrics dashboard: a single-page web app that displays income, outcome (expenses), profit, and profit margin for a business, broken down monthly, with supporting charts.

## Who it's for
An educational project built for 4Geeks Academy's AI Engineering track. It serves two purposes at once:
1. As a sample product: a small but realistic full-stack app (React + FastAPI) that a business owner or finance team could use to see income vs. expenses at a glance.
2. As a practice repository: students fork it to practice generating project context, writing `.agents/rules`, and building a `memory-bank` from an existing, unfamiliar codebase — which is exactly what this document is part of.

## What the dashboard shows
- **4 KPIs**: total income, total outcome, profit, profit margin (%)
- **2 charts**: income vs. outcome by month, profit percentage by month
- Movements can be filtered by category (`sales`, `suppliers`, `operational`, `administrative`, `others`), operation type (`income`/`outcome`), business type (`B2B`/`B2C`), and date range — via backend query params, though the current UI does not yet expose filter controls.

## Data source
All data is **mock data generated by the backend** on each request (see `tech-stack.md` and `current-status.md` for details) — there is no real database and no persistence. This is appropriate for the educational scope of the project.
