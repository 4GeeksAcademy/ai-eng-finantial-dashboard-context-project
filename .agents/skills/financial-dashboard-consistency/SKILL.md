# Financial Dashboard Consistency

## Objective

Keep financial data clear, consistent, and easy to compare across all dashboard components.

## Inputs

Review:

- Currency values
- Percentage values
- Dates and reporting periods
- Financial card titles and labels
- Positive and negative financial changes

## Instructions

1. Format currency consistently using the same currency style across the dashboard.
2. Use consistent decimal places for financial values.
3. Format percentages consistently, including positive and negative signs.
4. Use the same date format across all dashboard sections.
5. Keep financial labels clear and consistent.
6. Do not mix currencies unless the currency is clearly identified.
7. Do not change financial calculations or business logic.
8. Only make targeted formatting and naming improvements.

## Expected Output

The dashboard should display financial information using consistent formats, labels, units, and date styles.

## Acceptance Criteria

- Currency formatting is consistent.
- Percentages use the same format.
- Dates use one consistent style.
- Labels are clear and not duplicated.
- Positive and negative changes are easy to understand.
- No financial calculations or application behavior are changed.
